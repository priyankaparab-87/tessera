# FileUpload

Drop zone plus file list with progress and errors.

- Say accepted types and size in `hint`.
- Errors sit on the file that failed, not in a separate alert.

## When to use
Attach one or more files with drag and drop.

## Use something else
Pick from files already in the system → Combobox or List.

## Do
- Say accepted types and size limits in `hint`.
- Show progress and per-file errors in the list.

## Don't
- Don't clear the list when one file fails.
