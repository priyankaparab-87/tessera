# CopyInline

A value with its CopyButton. IDs in mono; long values truncate with a title tooltip.

## When to use
Show an ID, key or URL with a copy action next to it.

## Use something else
Copy button alone → CopyButton.

## Do
- Use `mono` for IDs; use `display` to shorten long values while copying the full one.

## Don't
- Don't use it for secrets; use PasswordField.
