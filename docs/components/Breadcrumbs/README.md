# Breadcrumbs

Shows where the page sits and links back up. The last item is the current page, unlinked and in `ui-strong`.

- Place at the top-left of the content, above the page title.
- The last item matches the page or tab the user is on.

## When to use
Show where a page sits in a hierarchy and link back up.

## Use something else
Flat apps with no hierarchy → omit.

## Do
- Put it above the page title; the last item is the current page.

## Don't
- Don't use it as the main navigation.
- Don't repeat the app name as the first crumb.
