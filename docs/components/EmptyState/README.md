# EmptyState

What to show when there is nothing yet, or nothing matches. Say why it's empty and offer the one action that fixes it.

## When to use
Explain why a list, table or page is empty and how to fill it.

## Use something else
Error loading data → Alert with a retry.

## Do
- Say why it's empty in one sentence and give the action that fills it.
- Differentiate “no data yet” from “no results for this filter” (offer Clear filters).

## Don't
- Don't use illustrations or jokes; one icon is enough.
