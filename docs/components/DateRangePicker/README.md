# DateRangePicker

Pick a start and end date, with quick presets. First click sets the start, second the end.

## When to use
Start and end dates: reporting periods, filters, bookings.

## Use something else
One date → DatePicker.

## Do
- Offer presets for common ranges (Last 7 days, This quarter).

## Don't
- Don't use two separate DatePickers for one range.
