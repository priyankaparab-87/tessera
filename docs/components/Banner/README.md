# Banner

Page- or app-level message that sits across the top of the content. Use for system state that affects the whole page; use Alert for a section.

## When to use
Page- or app-wide state: maintenance, trial ending, payments failing.

## Use something else
One section → Alert. Confirmation of an action → Toast.

## Do
- Place it at the top of the content, full width.
- Offer one action that resolves it.

## Don't
- Don't show more than one banner at a time.
- Don't use banners for marketing.
