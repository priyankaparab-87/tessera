# FilterPanel

Side panel of grouped filters for advanced filtering. Opens from FilterBar's “More filters”; applies on “Apply filters”.

## When to use
Many grouped filters in a side panel for data-heavy pages.

## Use something else
A few filters → FilterBar.

## Do
- Group filters with titles and counts; put Apply in the footer.

## Don't
- Don't apply filters on every click and also show an Apply button; pick one model.
