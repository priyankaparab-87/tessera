# Drawer

Side panel for details or edits while keeping the list in view. 400–560px wide; footer actions bottom-right.

## When to use
Show or edit details of an item while keeping the list or page behind it in view.

## Use something else
Blocking task → Dialog. Full detail with tabs and history → its own page.

## Do
- Use 400–560px width; put actions in the footer.
- Keep the title as the item's name or ID.

## Don't
- Don't stack drawers.
