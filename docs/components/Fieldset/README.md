# Fieldset

A titled section of a form. Use to break long forms into scannable groups; `columns={2}` for short paired fields.

## When to use
Group related fields in a long form under a heading (Shipping address, Billing).

## Use something else
Short form with 3–4 fields → no Fieldset needed.

## Do
- Give each section a clear `legend` and optional one-line `description`.
- Use `columns={2}` only for short, related fields (City / Postcode).

## Don't
- Don't nest Fieldsets.
