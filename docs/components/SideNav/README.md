# SideNav

App-level navigation down the left edge, under the AppHeader. 240px open, 56px collapsed to an icon rail.

- Every item has an icon and a label; collapsed items show the label as a tooltip.
- The current section uses `accent-subtle` with `text-accent`. Keep it to the app's top-level sections.

## When to use
Main app navigation with icons; collapses to a rail.

## Use something else
Few sections → TopNav. In-page → Tabs.

## Do
- Give every item an icon and a short label.
- Use `count` only for items that need attention.

## Don't
- Don't put actions (Create…) in the nav.
