# PageHeader

Top of every page: breadcrumbs, title, optional status badge, description and metadata, actions on the right, optional tabs underneath. One primary action.

## When to use
The top of every page: breadcrumbs, title, description, primary actions, optional tabs.

## Use something else
Section headings inside a page → Card titles or Fieldset legends.

## Do
- One primary action at most; put extra actions in a MenuButton.
- Use the `badge` for a count or status of the page's subject.

## Don't
- Don't repeat the page title in the content below.
