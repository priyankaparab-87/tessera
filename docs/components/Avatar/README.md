# Avatar

A person's initials (or photo) in a circle on `accent-subtle`.

- Sizes 24 (inline in tables), 28 (app header), 32 (default), 40 (profile headers).
- Always pass `name`; it supplies the initials and the accessible label.

## When to use
Represent a person: assignee, author, user menu.

## Use something else
Several people → AvatarGroup.

## Do
- Always pass `name` (initials and accessible label).

## Don't
- Don't use avatars for companies or objects; use an Icon.
