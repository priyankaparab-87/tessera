# Divider

A 1px rule that separates sections. `border` by default, `border-subtle` between rows inside a card; `vertical` inside toolbars.

## When to use
Separate groups of content inside a surface.

## Use something else
Space alone often works; use gap before adding lines.

## Do
- Use `subtle` inside cards.

## Don't
- Don't use dividers between every row of a list; List and Table already have them.
