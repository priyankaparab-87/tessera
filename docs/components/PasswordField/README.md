# PasswordField

Masked input with a show/hide toggle. Never pre-fill real secrets in designs.

## When to use
Secrets: passwords, API secrets.

## Use something else
Visible tokens people need to copy → CopyInline.

## Do
- Explain the rules in `description` before people type.
- Keep the show/hide toggle.

## Don't
- Don't block paste.
- Don't show strength rules only after an error.
