# KanbanColumn

A board column of cards for status-based workflows. Header shows status dot, name and count; empty columns say so instead of collapsing.

## When to use
A status column on a board, holding KanbanCards.

## Use something else
Comparing many fields → Table.

## Do
- Name columns after statuses; show the count.
- Show an empty message in empty columns.

## Don't
- Don't use more than ~6 columns.
