# CommandPalette

Keyboard-first search for navigation and actions, opened with ⌘K. Group results; show shortcuts; the first match is active.

## When to use
Keyboard-first jump to any page or action (⌘K).

## Use something else
Searching records in a list → SearchField.

## Do
- Group results (Go to, Actions) and show shortcuts.

## Don't
- Don't make it the only way to reach a feature.
