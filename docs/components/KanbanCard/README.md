# KanbanCard

A record card for boards: linked ID, priority badge, title, up to three fields, updated time and assignee.

## When to use
A record on a board: key, title, priority, a few fields, assignee.

## Use something else
Rich content → Card. Rows in a list → List.

## Do
- Keep to the key, a two-line title and up to 3 fields.

## Don't
- Don't put buttons inside the card; open details in a Drawer.
