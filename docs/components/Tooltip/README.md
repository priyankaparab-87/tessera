# Tooltip

Short, non-essential help on hover or focus. Never put actions or the only copy of important information in a tooltip. Icon buttons get their label as a tooltip.

## When to use
A short label or hint for an icon or truncated text, shown on hover and focus.

## Use something else
Information people must read → helper text or Alert. Interactive content → Popover.

## Do
- Keep it to a few words; add a `shortcut` when one exists.
- Use it on every IconButton (built in).

## Don't
- Don't put links or buttons in a tooltip.
- Don't hide essential instructions in a tooltip.
