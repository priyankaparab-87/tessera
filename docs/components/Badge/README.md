# Badge

A short, non-interactive label for status, priority or category.

- Tones carry meaning: `critical` (blocking, high priority, failed), `warning` (needs attention, medium), `success` (done), `info` (in progress), `accent` (highlighted), `new` (new or beta), `neutral` (default, low).
- Priority scale: Low = neutral, Medium = warning, High = critical.
- One or two words, sentence case. The word carries the meaning; colour only reinforces it. Use Tag for interactive labels.

## When to use
Show read-only status, priority or a count: Paid, High, Beta.

## Use something else
User-added labels or removable filters → Tag.

## Do
- Use one or two words; the word carries the meaning.
- Use tones consistently: success = done, warning = needs attention, critical = blocking.

## Don't
- Don't make badges clickable.
- Don't use status colours for decoration.
