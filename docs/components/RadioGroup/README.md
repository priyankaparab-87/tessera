# RadioGroup

Pick exactly one of 2–6 visible options. Use Select for longer lists.

- Always preselect a sensible default unless the choice must be deliberate.
- Add a `description` per option when the consequence differs.

## When to use
Pick exactly one of 2–6 options that people should compare before choosing.

## Use something else
More options → Select. View switching → SegmentedControl. On/off → Switch.

## Do
- Preselect the safest or most common option when there is one.
- Keep option labels parallel in grammar and length.

## Don't
- Don't use horizontal layout for long labels.
