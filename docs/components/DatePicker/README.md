# DatePicker

Pick one date. The field shows `2 Sep 2026` format; the calendar opens below.

## When to use
One date in a form: due date, delivery date.

## Use something else
A start and end → DateRangePicker. Date and time → DatePicker + TimePicker side by side.

## Do
- Show dates as “2 Sep 2026”.
- Default to today or the most likely date when it helps.

## Don't
- Don't ask people to type dates in an ambiguous format.
