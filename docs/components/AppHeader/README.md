# AppHeader

The 48px bar across the top of every app: brand and app name left, optional global search centre, tenant switcher and user right.

- Provide `appName`, and optionally `search`, `tenant`, `user`, `actions` (icon buttons) and `logo` (defaults to the Tessera mark).
- One per app, fixed to the top, above SideNav and content.

## When to use
The top bar of every app: brand, global search, tenant switcher, user menu.

## Use something else
Page title and actions → PageHeader.

## Do
- Use one per app, fixed at the top.

## Don't
- Don't put page-specific actions in the AppHeader.
