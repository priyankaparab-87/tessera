# TableToolbar

Replaces the table's toolbar when rows are selected: count, Clear, and bulk actions.

## When to use
The bar above a Table: search, filters, column options, export; bulk actions when rows are selected.

## Use something else
General page actions → PageHeader.

## Do
- Show `selectedCount` and bulk actions only while rows are selected.

## Don't
- Don't put row-specific actions here.
