# FilterBar

Search plus the most-used filters in one row above a list; active filters show as removable tags with Clear all. Put rare filters in FilterPanel behind “More filters”.

## When to use
2–4 inline filters plus search above a list or table, with applied filters as chips.

## Use something else
5+ filters or grouped filters → FilterPanel.

## Do
- Show applied filters as removable Tags with “Clear all”.

## Don't
- Don't hide the search inside “More filters”.
