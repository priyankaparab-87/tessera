# TopNav

Horizontal section navigation under the AppHeader, for apps with up to ~6 top-level sections. Use SideNav for more.

## When to use
Section navigation for products with a few (≤6) top-level areas.

## Use something else
More sections or nested areas → SideNav. In-page sections → Tabs.

## Do
- Highlight the current section; keep labels short.

## Don't
- Don't combine TopNav and SideNav for the same level.
