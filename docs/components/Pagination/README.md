# Pagination

Moves through pages of a table or list. Show the range summary when the total is known. Place below the table, right-aligned.

- Pass a distinct `label` when a page has more than one Pagination. Pages wrap under the summary in narrow containers.

## When to use
Move through pages of a long table or list (100+ rows).

## Use something else
Short lists → show all rows. Feeds → load more on scroll.

## Do
- Show the range summary when the total is known.
- Place it below the table, aligned right.

## Don't
- Don't paginate lists under ~50 items.
