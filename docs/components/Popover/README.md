# Popover

Non-modal panel anchored to a trigger for small, focused tasks. Closes on outside click or Esc. Use Dialog when the task blocks the page.

## When to use
A small, focused task anchored to its trigger: snooze until, quick edit, filter options.

## Use something else
Read-only hint → Tooltip. Larger task or form → Dialog or Drawer. List of actions → Menu.

## Do
- Keep it to a few controls and one primary action in the footer.
- Close on Esc and click outside.

## Don't
- Don't put a Popover inside another Popover.
