# CheckboxGroup

Several independent options under one label. Each checkbox can be on or off.

## When to use
Pick any number of options from a short list (up to ~8) that stay visible.

## Use something else
Exactly one option → RadioGroup. Long list → MultiSelect.

## Do
- Give the group a `label` (legend).
- Stack vertically unless there are 2–3 short options.

## Don't
- Don't nest groups more than one level.
