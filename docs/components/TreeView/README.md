# TreeView

Hierarchical list for folders, categories or org structures. Keep to 4 levels; selected row uses `accent-subtle`.

- Keyboard: Tab enters the tree once; ↑ ↓ move, → expands or enters, ← collapses or goes to the parent, Enter/Space selects. Long labels are cut with an ellipsis. Pass `label`.

## When to use
Navigate or pick from a hierarchy: folders, categories, org structure.

## Use something else
Flat list → List. Two levels → grouped List or Accordion.

## Do
- Keep to 4 levels or fewer.
- Pass `label` for screen readers.

## Don't
- Don't use it for tabular data; use Table.
