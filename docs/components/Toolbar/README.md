# Toolbar

A row of view and bulk controls above content. View options left, output actions right.

## When to use
A row of actions and controls above content: editor tools, view options.

## Use something else
Table-specific search, filters and bulk actions → TableToolbar.

## Do
- Group related controls; put the most used on the left.

## Don't
- Don't overflow the row; move extras into a MenuButton.
