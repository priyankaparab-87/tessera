# Stepper

Shows progress through a multi-step flow. Horizontal for wizards (3–6 steps), vertical for process status. Steps are nouns.

## When to use
Guide people through a multi-step form or setup in order.

## Use something else
Tracking real-world progress (order, shipment) → Timeline horizontal. Independent sections → Tabs.

## Do
- Keep to 3–6 steps with short labels.
- Mark errors on the step that has them.

## Don't
- Don't let people skip required steps without saying so.
