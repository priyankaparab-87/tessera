Components

78 components, mounted from window.Tessera. Each page has a live preview, when to use it, what to use instead, and do and don't.

Foundations

ThemesSwitches for the accent colour and typeface, with a live WCAG check of every accent pair. IconOutline icons on a 24px grid with a 1.5px stroke and round caps; they paint with `currentColor`, so set the colour on the parent.

Actions

ButtonTriggers an action. IconButtonA square button with one icon, for compact or repeated actions (row menus, close, refresh). ButtonGroupGroups related buttons. SplitButtonA primary action with related alternatives in an attached menu. ToggleButtonA button that stays on or off (`aria-pressed`). SegmentedControlSwitches between 2–5 mutually exclusive views or modes of the same content. LinkNavigates somewhere. CopyButtonCopies a value to the clipboard and confirms with a check for 1.6s.

Forms

TextFieldSingle-line text input with label, help and error text. TextAreaMulti-line text. NumberFieldNumeric input with stepper buttons. PasswordFieldMasked input with a show/hide toggle. SearchFieldText input for search with a leading search icon and a clear button once filled. SelectPick one option from a short list (up to ~15). ComboboxA searchable single select for long lists (people, products, countries). MultiSelectPick several options; selections show as removable Tags inside the field. CheckboxTurns an option on or off as part of a form that is saved later. CheckboxGroupSeveral independent options under one label. RadioA single radio; normally used through RadioGroup. RadioGroupPick exactly one of 2–6 visible options. SwitchAn immediate on/off setting that takes effect without a Save button. SliderChoose a value from a continuous range when precision matters less than feel. CalendarMonth grid used by DatePicker and DateRangePicker. DatePickerPick one date. DateRangePickerPick a start and end date, with quick presets. TimePickerPick a time from a list at `step` minutes between `startHour` and `endHour`. FileUploadDrop zone plus file list with progress and errors. InlineEditEdit a single value in place, on read-heavy pages. FieldsetA titled section of a form.

Overlays

MenuA list of actions. MenuButtonA button that opens a Menu. PopoverNon-modal panel anchored to a trigger for small, focused tasks. TooltipShort, non-essential help on hover or focus. DialogModal window for a focused task that blocks the page. ConfirmDialogAsks for confirmation before a destructive or irreversible action. DrawerSide panel for details or edits while keeping the list in view. ToastBrief confirmation that floats bottom-left and disappears after ~5s. CommandPaletteKeyboard-first search for navigation and actions, opened with ⌘K.

Feedback

AlertAn inline message about the page or a section. BannerPage- or app-level message that sits across the top of the content. ProgressBarShows progress of a task or how full something is. SpinnerAn indeterminate loading indicator that inherits `currentColor`. SkeletonPlaceholder shapes while content loads (under ~2s use nothing; over that, a skeleton matching the final layout). EmptyStateWhat to show when there is nothing yet, or nothing matches.

Navigation

TabsSwitches between views of the same object. TopNavHorizontal section navigation under the AppHeader, for apps with up to ~6 top-level sections. BreadcrumbsShows where the page sits and links back up. PaginationMoves through pages of a table or list. StepperShows progress through a multi-step flow. AccordionStacked sections that expand to show detail. TreeViewHierarchical list for folders, categories or org structures.

App chrome

AppHeaderThe 48px bar across the top of every app: brand and app name left, optional global search centre, tenant switcher and user right. SideNavApp-level navigation down the left edge, under the AppHeader.

Data display

TableA data table for scanning and comparing records. BadgeA short, non-interactive label for status, priority or category. TagInteractive keywords, filters or people. TagGroupWraps several Tags with consistent spacing. AvatarA person's initials (or photo) in a circle on `accent-subtle`. AvatarGroupOverlapping avatars for watchers or participants, with a “+N” for the rest. KbdKeyboard keys in help text, menus and tooltips. CodeInlineCode or literal values inside a sentence. CodeBlockMulti-line code with a copy button. CopyInlineA value with its CopyButton. DescriptionListLabel–value pairs for record details. StatA KPI tile: label, big number, change. TimelineActivity history or progress through milestones. CommentA note or message by a person, with actions. ListRows of simple records (people, files, settings).

Layout

CardA `surface` container on `bg-page` with `border`, `radius-lg` and `shadow-sm`. DividerA 1px rule that separates sections.

Patterns

PageHeaderTop of every page: breadcrumbs, title, optional status badge, description and metadata, actions on the right, optional tabs underneath. ToolbarA row of view and bulk controls above content. TableToolbarReplaces the table's toolbar when rows are selected: count, Clear, and bulk actions. FilterBarSearch plus the most-used filters in one row above a list; active filters show as removable tags with Clear all. FilterPanelSide panel of grouped filters for advanced filtering. KanbanColumnA board column of cards for status-based workflows. KanbanCardA record card for boards: linked ID, priority badge, title, up to three fields, updated time and assignee.

Choosing between look-alikes

  • Badge or Tag: Badge is read-only status; Tag is interactive (removable, selectable).
  • Alert, Banner or Toast: Alert belongs to a section; Banner spans the page for system state; Toast confirms the user's own action and disappears.
  • Dialog, Drawer or Popover: Dialog blocks the page for a focused task; Drawer shows details beside the list; Popover handles a small task anchored to its trigger.
  • Select, Combobox or RadioGroup: RadioGroup for 2–6 visible options; Select for up to ~15; Combobox when people need to search.
  • Tabs, SegmentedControl or TopNav: Tabs switch content within a page; SegmentedControl switches the view of the same content; TopNav moves between app sections.
  • Table, List or Kanban: Table to compare columns; List for simple records; Kanban for status-based workflows.
